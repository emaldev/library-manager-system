# Library Management System 📚

A desktop application built with **Java Swing** for managing books in a library.

This project demonstrates Object-Oriented Programming (OOP), GUI development, and file handling in Java.

## Features ✨

* ➕ Add new books
* 🗑️ Remove books by ID
* 🔍 Search books by title
* 📖 Display all books
* 💾 Save library data to a text file
* 📂 Load library data from a text file
* 🚪 Exit application
